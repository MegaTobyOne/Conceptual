# Flagship Jobs

This C0 evidence pack is a deterministic, offline simulated-operator substitute. It is weaker than observed-user evidence and is not presented as validation.

| ID  | Job                                                                             | Start state                                        | Answered state                                               |
| --- | ------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------ |
| FJ1 | Establish why a requirement is currently compliant, and on what basis           | A requirement is available in Explorer or Workshop | The current status and its basis are visible                 |
| FJ2 | Take an unmet requirement to an owned, dated action with recorded rationale     | An unmet requirement is open in Workshop           | The action has an owner team, due date, and rationale record |
| FJ3 | Produce this reporting season's Domain pack for a Domain I own                  | A reporting workspace is open in Workshop          | The scoped Domain pack is ready for review                   |
| FJ4 | Establish what changed since the last reporting period, and which of it matters | Current and prior reporting periods are available  | The changed items and materiality rule are visible           |

Cost records count route changes, distinct surfaces opened, discrete input events, and the first answer-visible step. Wall-clock time and operator identity are intentionally absent.
