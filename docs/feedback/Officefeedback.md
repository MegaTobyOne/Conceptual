# Compliance Officer Feedback

## Overall impression

The solution is promising and the underlying capability appears sound, but completing a targeted compliance update felt harder than necessary. The interface should better support a focused operational workflow without hiding advanced capability from users who need it.

## Intended workflow

Following a significant event, I need to:

1. Search for a keyword to identify the applicable requirement.
2. Open and update that requirement.
3. Add actions and link supporting evidence.
4. Confirm that the changes were saved.
5. Understand the effect on results, posture and risk.

## Experience and pain points

- It was not immediately clear where requirements could be found.
- The available dropdown made it feel necessary to know the exact requirement in advance, rather than allowing me to search and explore.
- Explorer browsing feels better suited to discovering requirements, while Workshop and Core provide the focused retrieval and editing capability I need. These experiences currently feel separate.
- The advanced feature set is valuable, but it should not dominate the default experience for a user completing a focused update.

## Design implications

- Provide consistent requirement discovery, search and retrieval across Explorer, Workshop and Core.
- Support a direct path from keyword search to requirement editing, actions and evidence links.
- Make save status and the resulting change to posture and risk visible after an update.
- Offer a simplified, task-focused default interface with advanced functions available when required.
