# Future Mission Control Prototype Test Checklist

Status: draft
Last updated: 2026-07-01

## Goal

Validate whether the integrated Future Mission Control concept improves clarity, momentum, and future-planning confidence compared with existing flow patterns.

## Test setup

1. Open `docs/mockups/future-mission-control-prototype.html` in a browser.
2. Use one realistic PSPF scenario and role context.
3. Run tests in desktop and mobile-sized viewport.
4. Repeat with keyboard-only navigation.

## Task script

1. Read the default mission state and identify the top next decision.
2. Switch from Operator to Executive mode and explain what changed.
3. Switch to Assurance mode and identify one evidence weakness.
4. Trigger Ripple Preview and summarise downstream impact.
5. Explain the difference between Now, Next, and Later lanes.
6. State the minimum viable path from the left panel.

## Success criteria

1. Participant can explain top decision in under 45 seconds.
2. Participant can distinguish audience modes without coaching.
3. Participant can describe confidence shift after ripple preview.
4. Participant correctly interprets horizon lanes as future planning states.
5. Participant reports that the interface feels clear and motivating.

## Accessibility checks

1. All controls are reachable and operable by keyboard.
2. Focus visibility is obvious on interactive elements.
3. Status meaning is not colour-only.
4. Layout remains usable at 200% zoom.
5. Motion-heavy behaviour is optional.

## Exit questions

1. Would this make planning easier than your current workflow?
2. Which mode was most useful for your role?
3. Did the time horizon make decisions clearer?
4. What should be removed to reduce friction?
5. What should be added to improve trust?
